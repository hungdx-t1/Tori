Tori, the modular Discord bot development framework.

The documentation is split into respective modules (tori-api, tori-base) and packages for each subject matter. This documentation covers developer-facing interfaces, asynchronous interaction pipelines, and concurrency tools.

For basic command registration, see the commands package. For async execution, see the concurrent package (powered by FutureAction).

Note on Concurrency & Threading:
  • Avoid invoking blocking calls (such as .complete()) on Discord Gateway event threads.
  • Use FutureAction.retryWhen(...) or reactive patterns for network-sensitive operations.
