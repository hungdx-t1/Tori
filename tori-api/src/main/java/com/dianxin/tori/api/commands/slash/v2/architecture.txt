Dưới đây là một bản thiết kế Command API Framework dạng Context-Based kết hợp Dual-Registry
(Slash Command + Text Prefix), được may đo chuẩn cho kiến trúc Modular Bot (như framework Tori của bạn).

Kiến trúc tổng quan (Architecture Overview)

[Discord Event: Slash / Text]
             │
             ▼
   [CommandEventDispatcher] (Lắng nghe JDA Event)
             │
   ┌─────────┴─────────┐
   ▼                   ▼
[SlashContext]     [TextContext] ──► Implement [ICommandContext]
   │                   │
   └─────────┬─────────┘
             ▼
      [Pipeline / Guard] ──► (Kiểm tra Cooldown, GuildOnly, Permissions)
             │
             ▼
     [AbstractCommand] ────► execute(ICommandContext ctx)

5. Cách triển khai một lệnh cụ thể (Clean & Ngắn gọn)
public class PingCommand extends BaseCommand {

    public PingCommand() {
        super("ping", "Kiểm tra độ trễ của Bot");
        addAliases("p", "latency");
        setGuildOnly(true);
    }

    @Override
    public void execute(ICommandContext ctx) {
        long gatewayPing = ctx.getJDA().getGatewayPing();
        ctx.reply("🏓 Pong! Gateway latency: `" + gatewayPing + "ms`");
    }
}
